# Ruaa Al-Bataineh — Personal Portfolio

A modern, responsive personal portfolio website built to showcase my skills, projects, education, certificates, and contact information.

## About the Project

This portfolio website represents my work and experience as a Software Engineer. It provides an overview of my technical skills, personal projects, educational journey, and ways to connect with me.

The website focuses on a clean, modern, and responsive design that works across desktop, tablet, and mobile devices.

## Features

* Responsive design
* Modern dark-themed user interface
* Smooth scrolling navigation
* Mobile navigation menu
* Active navigation link based on scroll position
* Scroll reveal animations
* Interactive hero image animation
* Skills section with visual skill levels
* Projects showcase
* Certificates and learning section
* Contact section
* Social media links
* GitHub project links
* Dynamic current year in the footer
* Download CV button

## Technologies

* HTML5
* CSS3
* JavaScript
* Font Awesome

## Getting Started

To run the portfolio locally:

1. Clone the repository.
2. Open the project folder.
3. Open `index.html` in your browser.

No backend server or database is required.
